# Interview Notes

## Universal Explanation

```text
The stack stores unresolved candidates.

When a better candidate arrives,
elements that can no longer help
are removed.

Each element is pushed once
and popped once.

Therefore:

O(N)
```

---

## Why Is Popping Safe?

Interview Answer:

```text
The current element dominates
the popped element.

Any future element would prefer
the current element because it is:

1. Closer
2. Better candidate

Therefore the popped element
can never be useful again.
```

---

## Why Monotonicity Helps

```text
Without ordering:

Too many useless candidates.

With ordering:

Only useful candidates survive.
```

---

## Value vs Index Rule

Question:

```text
Should I store values or indices?
```

Rule:

```text
Need distance/boundary?
→ Store indices

Need only value?
→ Values may be enough
```

Most interview solutions become easier with indices.

# Interview Ready Solutions

## LC 503 — Next Greater Element II

```cpp
class Solution {
public:
    vector<int> nextGreaterElements(vector<int>& nums) {
        int n = nums.size();
        stack<int> nge;              // indices waiting for NGE
        vector<int> res(n, -1);

        // Traverse twice to simulate circular array
        for(int i = 0; i < 2 * n; i++) {

            // Current element resolves all smaller waiting elements
            while(!nge.empty() &&
                  nums[i % n] > nums[nge.top()]) {

                int idx = nge.top();

                // Answer only once
                if(res[idx] == -1)
                    res[idx] = nums[i % n];

                nge.pop();           // fully resolved
            }

            nge.push(i % n);         // wait for future greater element
        }

        return res;
    }
};
```

### Memory Hook

```text
Stack = unresolved indices

Current greater element
resolves smaller waiting indices

2*n traversal
simulates circular array
```

## LC 901 — Stock Span

```cpp
class StockSpanner {
public:

    stack<pair<int, int>> st;    // {day, price}
    int day = 0;

    StockSpanner() {
    }

    int next(int price) {
        day++;

        // Remove smaller/equal prices; current price dominates them
        while(!st.empty() && price >= st.top().second)
            st.pop();

        // Span = distance from previous greater price
        int span = (!st.empty()) ? day - st.top().first : day;

        // Current price becomes a candidate previous greater
        st.push({day, price});

        return span;
    }
};
```

### Memory Hook

```text
Stack = candidate previous greater prices

Current price
removes weaker blockers

Top after popping
= nearest greater on left

Span
= currentDay - previousGreaterDay
```
