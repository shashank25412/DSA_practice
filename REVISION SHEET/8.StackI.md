# Stack Foundations - Pattern Mastery Notes

## Core Mental Models

### Family 1: History Management

Question:

```text
What information from the past must I remember?
```

Mental Model:

```text
Push = Remember
Pop  = Undo / Resolve
```

Stack stores:

```text
Recent unfinished history
```

Examples:

* LC 20 Valid Parentheses
* LC 682 Baseball Game
* LC 844 Backspace String Compare

---

### Family 2: Deferred Resolution

Question:

```text
Can I answer this now?
```

If not:

```text
Store it and wait for future information.
```

Mental Model:

```text
Push = Question enters waiting room
Pop  = Question gets answered
```

Stack stores:

```text
Unresolved questions
```

Examples:

* LC 739 Daily Temperatures
* LC 496 Next Greater Element I

---

## LC 739 - Daily Temperatures

Family:

```text
Deferred Resolution
```

Store:

```text
Indices whose answer is unknown
```

Question:

```text
When is my next warmer day?
```

Pop Condition:

```text
temp[curr] > temp[top]
```

Answer Relation:

```text
answer[top] = curr - top
```

Invariant:

```text
Stack contains unresolved days.
```

Monotonic Property:

```text
temp[stack[0]]
>=
temp[stack[1]]
>=
temp[stack[2]]
```

Remember:

```text
Current day resolves older days.
```

## LC 496 - Next Greater Element I

Family:

```text
Deferred Resolution
```

Store:

```text
Values waiting for greater value
```

Question:

```text
What is my next greater element?
```

Pop Condition:

```text
curr > top
```

Answer Relation:

```text
NGE[top] = curr
```

Invariant:

```text
Stack contains unresolved values.
```

Monotonic Property:

```text
Decreasing stack
```

Special Twist:

### Phase 1

Build answer key from nums2

```text
value → nextGreaterValue
```

Example:

```text
1 → 3
3 → 4
4 → -1
2 → -1
```

### Phase 2

Answer nums1 using lookup

```text
result[i] = map[nums1[i]]
```

Remember:

```text
nums2 builds answers.
nums1 asks questions.
```

# Monotonic Stack Framework

Recognition:

```text
Need nearest greater/smaller element.
```

Invariant:

```text
Stack contains unresolved elements.
```

Generic Template:

while(current resolves top)
{
answer[top] = ...
pop();
}

push(current);

---

Common Relations

Next Greater:

```text
curr > top
```

Next Smaller:

```text
curr < top
```

Warmer Day:

```text
temp[curr] > temp[top]
```

Days Difference:

```text
currIndex - topIndex
```
