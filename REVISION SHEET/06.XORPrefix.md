# Stage 3C — Prefix XOR Pattern

## Mental Shift

**Prefix Sum world**
- Remove overlap using subtraction
- `sum(L,R) = prefix[R] - prefix[L-1]`

**Prefix XOR world**
- Remove overlap using cancellation
- `xor(L,R) = prefixXor[R] ^ prefixXor[L-1]`

Core mental model:

> Difference logic, but in XOR world.

---

## XOR Intuition

Think of XOR as:

> Same things cancel. Different things survive.

### Why XOR cancels

- `x ^ x = 0`
- `x ^ 0 = x`

Anything appearing twice disappears.

Example:

`2 ^ 5 ^ 2`

The two `2`s cancel.

Result:

`5`

---

## XOR Laws

1. Cancellation

`x ^ x = 0`

2. Identity

`x ^ 0 = x`

3. Self reversible

`a ^ b ^ b = a`

4. Commutative

`a ^ b = b ^ a`

5. Associative

`(a ^ b) ^ c = a ^ (b ^ c)`

## Prefix XOR Formula

`prefixXor[i] = xor(0...i)`

Subarray XOR:

`xor(L,R) = prefix[R] ^ prefix[L-1]`

Why?

Common prefix cancels.

## Master Templates

### 1. XOR Accumulator

### Use When
- Single Number
- Odd occurrence
- Duplicate cancellation

```cpp
int x = 0;

for(int num : nums){
    x ^= num;
}

return x;
```

Complexity:
- O(n)
- O(1)

---

### 2. Prefix XOR Array

### Use When
- Range XOR query
- Multiple queries

```cpp
vector<int> prefix(n);

prefix[0] = arr[0];

for(int i=1;i<n;i++){
    prefix[i] = prefix[i-1] ^ arr[i];
}
```

Query:

```cpp
if(L == 0)
    return prefix[R];

return prefix[R] ^ prefix[L-1];
```

Complexity:
- Preprocess: O(n)
- Query: O(1)

---

### 3. Prefix XOR + HashMap (560-style XOR)

### Use When
- Count subarray XOR = K

Derivation:

`curr ^ old = K`

So:

`old = curr ^ K`

```cpp
unordered_map<int,int> freq;

freq[0] = 1;

int prefixXor = 0;
int count = 0;

for(int num : nums){

    prefixXor ^= num;

    int needed = prefixXor ^ k;

    count += freq[needed];

    freq[prefixXor]++;
}

return count;
```

Invariant:

> What previous prefix XOR completes target K?

Complexity:
- O(n)
- O(n)

---

### 4. LC 1442 Pattern

Equal prefix XOR means:

`xor(i...k) = 0`

Every split works.

Contribution:

`k - prevIndex`

Why?

Because every valid split point works.

```cpp
unordered_map<int, pair<int,int>> mp;
// xor -> {count, indexSum}
```

## Prefix Sum vs Prefix XOR

| Thing | Prefix Sum | Prefix XOR |
|---|---|---|
| Remove overlap | subtraction | cancellation |
| Formula | `P[R]-P[L-1]` | `P[R]^P[L-1]` |
| Reverse op | subtraction | XOR itself |
| HashMap equation | `curr-k` | `curr^k` |
| Mental model | remove contribution | cancel overlap |

---

## Common Mistakes

1. Using subtraction instinct

Wrong:

```cpp
curr - k
```

Correct:

```cpp
curr ^ k
```

2. Forgetting:

```cpp
freq[0] = 1;
```

3. Missing `L == 0`

4. Confusing duplicates vs overlap cancellation

Prefix XOR cancels overlap, not duplicates globally.

5. LC 1442 off-by-one

Correct:

`k - prevIndex`
