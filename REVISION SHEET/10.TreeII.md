# 🌳 Phase 3 — Recursive State Propagation (Summary Notes)

## Core Idea
Tree recursion is not just “ask children and combine”.

It is:

> **State flows DOWN (context) + Result flows UP (answer)**

Each recursive call:

Receive state → Transform state → Recurse → Combine → Return


---

## 🧠 Mental Model

### Two independent channels:

### ↓ Downward (State)
- Context passed from parent → child
- Defines the *subproblem*

Examples:
- remaining target
- current path
- current number
- prefix map

### ↑ Upward (Return)
- Answer passed child → parent
- Solves parent’s question

Examples:
- boolean
- height
- node
- max/min
- count

---

## ⚠️ Key Principle

> **Immutable state is propagated (no restore needed)**  
> **Mutable state is shared (needs backtracking)**

# Master Insight (Phase 3)

Tree recursion is not traversal — it is state transformation per node

Each node:

1. Receives state
2. Transforms state
3. Sends state down
4. Receives result
5. Combines result
